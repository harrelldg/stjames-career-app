# TeamUnlock+ Mobile Prototype

Expo/React Native implementation of the St James Career App concept.

## Run locally

```bash
npm install
npm start
```

Scan the Expo QR code with a compatible device, or use `npm run android` / `npm run ios` with the required simulator setup. The app uses Expo 54 and its default icons/splash screens; no custom binary assets are required.

## Prototype scope

- Six sequential scenario levels with five questions each.
- Cumulative career-interest scoring shared with the profile and student report.
- Native text sharing through the device share sheet.
- Fixed, clearly labelled institutional sample data.
- Camera preview with runtime permission; no AR tracking, recording or upload.

Progress is held in memory only and resets on restart. Results are illustrative, not a validated assessment or career advice.
